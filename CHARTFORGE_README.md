## ✨ Features

### 🎨 **Modern Glass-morphism UI**
- Beautiful glass-effect cards with backdrop blur
- Spatial depth hierarchy with layered shadows
- Spring-based micro-animations
- Deep indigo + vibrant gradient palette

### ☁️ **Cloud Sync & Collaboration**
- Supabase authentication & cloud storage
- Real-time sync across devices
- Project sharing with permissions
- Team workspaces

### 🔗 **Live Data Connectors**
- REST APIs, Google Sheets, Airtable
- CSV URLs, SQL databases
- Auto-refresh & webhooks
- OAuth authentication

### 📊 **Enhanced Charts**
- 14+ interactive chart types
- Custom tooltips & animations
- Drill-down navigation
- Zoom & pan controls

### 🎭 **Template System**
- 10+ pre-configured templates
- Business, Finance, Marketing categories
- Template gallery & search
- Save custom templates

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Configure Supabase (optional):
1. Copy `.env.example` to `.env`
2. Add your Supabase credentials
3. Run SQL migrations from README

---

## 📖 Usage

1. **Import Data** — Upload CSV/JSON or connect live sources
2. **Choose Template** — Browse gallery or start from scratch
3. **Customize** — Edit colors, labels, and configurations
4. **Edit Data** — Modify values, add/remove rows inline
5. **Export & Share** — PNG, SVG, or cloud sync

### Keyboard Shortcuts
- `Ctrl+S` Save • `Ctrl+N` New • `Ctrl+E` Export
- `Ctrl+Z` Undo • `Ctrl+Shift+Z` Redo
- `Ctrl+D` Theme • `?` Shortcuts

## 🎨 Design System

- **Primary**: Deep Indigo `hsl(234, 89%, 58%)`
- **Accent**: Vibrant Purple `hsl(270, 95%, 75%)`
- **Fonts**: Space Grotesk, Inter, JetBrains Mono
- **Animations**: Spring-based cubic-bezier

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **UI**: Radix UI, shadcn/ui, Tailwind CSS
- **Charts**: Recharts
- **Animations**: Framer Motion
- **Backend**: Supabase
- **Icons**: Lucide
